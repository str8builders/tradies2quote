# T2QCAL web release

Decision: 9 September 2026. The user wants T2QCAL delivered as an installable web app now. Preserve the existing SwiftUI project for a later App Store release; do not continue presenting Simulator builds as the current release deliverable.

The web app lives at `/t2qcal/`, with an independent manifest ID `/t2qcal`, start URL `/t2qcal/calculators` and standalone display. Tradies2Quote remains a separate app. Its dashboard should not gain calculator launch panels.

## Runtime

- Calculator pages run their calculations in the browser.
- The separate `/t2qcal/sw.js` service worker caches public calculator HTML and static assets. It must never cache account APIs, sign-in pages, saved-query URLs or the quoting app.
- A calculator must be opened online before offline reopening is guaranteed. The directory, device library, installation help and an honest offline fallback are installed with the worker.
- Public navigation uses ordinary links to avoid relying on online Next.js RSC requests while offline.
- Device-saved working is explicitly browser-local, not account-scoped. The device library validates every snapshot before saving or restoring. A malformed library is never silently replaced. Backup import is atomic, respects the 100-entry limit and preserves newer existing records.
- Account working and quote transfer remain online features. A cloud save clears the device URL fragment so reopening cannot accidentally prefer an older local snapshot.

## Release checks

Check the installed app's name, icon, scope and start URL separately from Tradies2Quote. Verify calculator edits, device save/reopen, backup restore, offline reload, and separate account storage. Keep geometry tests against the native source; 36 stair fixtures are generated by the native project's `tools/ExportStairParity.swift`.

This does not claim complete native feature parity. Native AR/camera measurement and room scanning are unavailable in this web release. Blocklayer coverage and remaining native workflows require further porting and validation. Bump the service worker cache version whenever its public runtime changes.

## 9 September 2026 — native app is the specification

The owner rejected the earlier separate web calculator layout. The web runtime must port the existing native T2QCAL app rather than establish a second design. Preserve the SwiftUI project for later Apple submission.

This change uses the native T2QMark asset, Archivo/IBM Plex fonts, Theme palette, ToolListView hero, category/order/summary data and RootView's four tabs. `native-catalog.json` is generated from all native Models/Engine sources using `t2qcal/scripts/native-web-export/main.swift` (native baseline a19626e).

Ported the three previously absent native tools: pipe-fall, spouting-downpipes and paving-ring. Their geometry is compared against 18 fixtures generated by the actual Swift models. The web catalog now has all 95 native entries. This does not establish complete numerical/diagram parity for the other 92 existing web implementations.

Jobs can group device-saved calculations and reopen their exact snapshots. Resources lists the native library's 76 publisher references; browser downloads are manual. The Measure tab explains that browser ARKit/RoomPlan is unavailable. Native job import/sync, native commercial job-line workflows, automatic offline PDF library/import and full native diagram/field parity are still outstanding. Do not describe these adaptations as a completed native feature conversion or claim App Store readiness.

Validation: 440 calculator and storage tests; TypeScript and scoped ESLint; phone-width browser/native home comparison; create job, save modified 12,500 mm pipe run and reopen it from Jobs. No database changes in this release.

## 9 September 2026 — straight-stair native parity follow-up

Added native stringer width and tread thickness fields, remaining throat and first-riser results. Existing saved stair snapshots receive native defaults on read without mutating the original object. Native invalid-throat/thick-tread checks reject impossible geometry. All four native views are available; flat stringer notches follow `StairGeometry.notchPath` with exact rise/run segments and ruler scale. Straight-stair 3D now uses actual tread count, width, rise, run and material thickness instead of the generic 14-riser illustration. Phone browser checks cover template ruler, invalid input, metric/inch conversion and device save. 444 calculator/storage checks passed, including 36 native Swift stair references and exact perpendicular-notch checks for 2–60 rises. Full app parity is still not claimed.
